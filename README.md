# xmas-illumination

100円ショップの電池式 LED イルミネーションを USB 給電にし、ESP32 で光り方を制御するためのリポジトリです。

## 構成

| 項目 | 内容 |
|---|---|
| マイコン | ESP32-DevKitC-32E |
| ドライバー | TB6612FNG（秋月電子 AE-TB6612-BO） |
| 電源 | USB-A 充電器（5V） |
| LED | 40球セット×3（LED が半分ずつ逆向きに接続されている）、10球セット×2 |
| 操作 | タクトスイッチ 1 個 |

40球セットの LED は半分ずつ逆向き（逆並列）に接続されているため、H ブリッジで電流の向きを 1 秒に 200 回入れ替えて、両方向の LED を点灯させています。3 セットは同じ光り方とし、1 チャンネルにまとめて接続します。LED の線 1 本ごとに 33Ω（1/2W）の抵抗を入れます。

## 配線

| ESP32 | 接続先 |
|---|---|
| GPIO25 | TB6612 AIN1 |
| GPIO26 | TB6612 AIN2 |
| 3.3V | TB6612 PWMA、STBY、VCC |
| GND | TB6612 GND、タクトスイッチ |
| GPIO27 | タクトスイッチ（内部プルアップを使用） |

TB6612 の VM には USB の 5V、AO1・AO2 には 33Ω を介して 40 球セットの線を接続します。

TB6612 の到着前は、GPIO25 と GPIO26 の間に 220Ω と逆向きに並べた LED 2 個を接続して動作を確認しています。

## 操作

| 操作 | 動作 |
|---|---|
| ボタンを短く押す | 次のパターンへ切り替え（停止中は最後のパターンで再開） |
| ボタンを長押し（0.8 秒） | 停止／再開 |
| 電源投入 | 最後に選んだパターンで点灯 |

パターンは、全点灯、交互点滅、全点滅、ふわっと、追いかけ、ろうそく、きらめき、ハートビート、フラッシュ、だんだん速く、自動めぐり（20 秒ごとに切り替え）の順に切り替わります。

シリアルモニター（115200bps）からも、キー入力でパターンと明るさを変更できます（1〜9、a、b、0、+、-）。

## 開発

[PlatformIO](https://platformio.org/) を使用しています。

```bash
cd firmware
pio run                 # ビルド
pio run -t upload       # 書き込み
pio device monitor      # シリアルモニター
```

書き込みが途中で失敗する場合があるため、`platformio.ini` で書き込み速度を 115200bps に下げています。

## 今後の予定
